# Security Policy

FoxyTunnel is not ready for security-sensitive use yet.

Please do not report early development limitations as vulnerabilities unless
they contradict documented behavior. Examples of expected early limitations are:

- UDP traffic is unsupported unless explicitly documented otherwise.
- DNS handling is still being designed.
- Tunnel mode may require administrator privileges on Windows.

When reporting a security issue, include:

- affected version or commit,
- Windows version,
- reproduction steps,
- expected behavior,
- observed behavior.
